# Codemods

## Overview

The Codemods Project Area focuses on the development, documentation, maintenance, and usage of official codemods for upgrading and maintaining Backstage projects. This includes ensuring automated transformations are reliable, well-tested, and aligned with changes across the Backstage ecosystem.

## Scope

The scope of the Codemods Project Area encompasses:

- **Codemod Development:** Development, documentation, maintenance, and improvement of official Backstage codemods in the [codemods repository](https://github.com/backstage/codemods).
- **Migration Tooling:** Ensuring proper and effective tooling for automated code migrations across Backstage versions.
